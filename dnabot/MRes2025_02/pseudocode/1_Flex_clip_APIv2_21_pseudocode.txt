PROTOCOL: "DNABOT Step 1 – Clip Reaction with thermocycler"
ROBOT: Flex 
API level: 2.21



ROBOT CONTEXT

- robot_type := __HARDWARE["robot_type"]["id"] ∈ {"Flex","OT-2"}
- Using (Flex default configuration):

  - Single-channel 50 µL pipette (Flex_1channel_50) on right mount
  - Thermocycler Module Gen2 in deck location B1
  - Flex 96-tip 50 µL tiprack for clip setup
- Using (OT-2 alternative configuration):

  - Single-channel P20 (p20_single_gen2) on right mount
  - Thermocycler Module Gen2 in default OT-2 thermocycler position
  - OT-2 96-tip 20 µL tiprack



CLIP INPUT MAP (clips_dict)

- 12 clip reactions total (n_reactions = len(parts_wells) = 12).

- For each reaction i:

  - prefix source: (prefixes_plates[i], prefixes_wells[i])
  - suffix source: (suffixes_plates[i], suffixes_wells[i])
  - part source:   (parts_plates[i],   parts_wells[i]) with volume parts_vols[i] µL
  - water volume:  water_vols[i] µL

- In this Flex-adapted layout:

  - All prefixes and suffixes are on plate "D2" (linker source plate).
  - All parts are on plate "C2" (part source plate).
  - Example (just to illustrate geometry):

    - Reaction 1:

      - Prefix:  plate D2, well A8
      - Suffix:  plate D2, well B7
      - Part:    plate C2, well E2, volume 2.5 µL, water 7.5 µL
    - Reactions 2–12: analogous, with different wells and part volumes per clips_dict.



TIPRACK / PIPETTE SETUP

1. DETERMINE TIPRACK TYPE

   - If robot_type == "Flex":

     - tiprack_type := __LABWARES["tiprack_20ul"]["id"]
       → "opentrons_flex_96_tiprack_50ul"
   - Elif robot_type == "OT-2":

     - tiprack_type := __LABWARES["tiprack_20ul"]["id"]
       (in an OT-2-specific __LABWARES, would be "opentrons_96_tiprack_20ul")
   - Else:

     - RAISE error ("Invalid robot type. Must be 'OT-2' or 'Flex'.")

2. INITIAL TIP POSITION

   - INITIAL_TIP := "A1"  (first tip in first tiprack)

3. CANDIDATE TIPRACK SLOTS

   - If robot_type == "OT-2":

     - CANDIDATE_TIPRACK_SLOTS := ["3","6","9"]
   - If robot_type == "Flex":

     - CANDIDATE_TIPRACK_SLOTS := ["D3","C3","B3"]

4. DEFINE SINGLE-CHANNEL PIPETTE

   - PIPETTE_TYPE  := __HARDWARE["single_pipette"]["id"]

     - Flex default: "Flex_1channel_50"
     - OT-2 alternative: "p20_single_gen2"
   - PIPETTE_MOUNT := __HARDWARE["single_pipette_mount"]["id"] = "right"

5. TIP COUNTING (INSIDE clip())

   5.1 BUILD UNIQUE LINKER & PART SETS
   - prefixes_unique := unique (plate,well) pairs from (prefixes_plates, prefixes_wells)
   - suffixes_unique := unique (plate,well) pairs from (suffixes_plates, suffixes_wells)
   - parts_unique    := unique (plate,well) pairs from (parts_plates,    parts_wells)

   5.2 COMPUTE TOTAL TIPS NEEDED
   - If Mix_linkers_bool == True AND Mix_parts_bool == True:
   total_tips := (4 - len(parts_wells)) + len(prefixes_unique) + len(suffixes_unique) + len(parts_unique)
   - Elif Mix_linkers_bool == True AND Mix_parts_bool == False:
   total_tips := (4 - len(parts_wells)) + len(prefixes_unique) + len(suffixes_unique)
   - Elif Mix_linkers_bool == False AND Mix_parts_bool == True:
   total_tips := (4 - len(parts_wells)) + len(parts_unique)
   - Else:
   total_tips := 4 - len(parts_wells)

   
   (Here len(parts_wells) = 12, so baseline 48 tips for prefix/suffix/part transfers plus mixing tips.)  
   

   5.3 COMPUTE TIPS AVAILABLE IN FIRST RACK
   - letter_dict := {A:0, B:1, …, H:7}
   - tiprack_1_tips := (13 − int(INITIAL_TIP[1:])) - 8 − letter_dict[INITIAL_TIP[0]]
   → for INITIAL_TIP="A1": tiprack_1_tips = 96 tips

   5.4 COMPUTE NUMBER OF TIPRACKS
   - If total_tips > tiprack_1_tips:
   tiprack_num := 1 + floor((total_tips − tiprack_1_tips) / 96)
   + (1 if (total_tips − tiprack_1_tips) mod 96 > 0 else 0)
   Else:
   tiprack_num := 1

   5.5 SELECT TIPRACK SLOTS
   - slots := first tiprack_num entries from CANDIDATE_TIPRACK_SLOTS
   (Flex example: slots = ["D3"] if only one rack needed.)

   5.6 LOAD TIPRACKS
   - tipracks := [ protocol.load_labware(tiprack_type, slot) for slot in slots ]

6. LOAD PIPETTE

   - pipette := protocol.load_instrument(PIPETTE_TYPE, mount=PIPETTE_MOUNT, tip_racks=tipracks)



LABWARE SETUP

7. THERMOCYCLER AND DESTINATION CLIP PLATE

   7.1 LOAD THERMOCYCLER
   - If robot_type == "Flex":
   tc_mod := protocol.load_module(__HARDWARE["thermocycler"]["id"], location="B1")
   - Else (OT-2):
   tc_mod := protocol.load_module(__HARDWARE["thermocycler"]["id"])

   7.2 INITIALIZE THERMOCYCLER
   - tc_mod.open_lid()
   - tc_mod.deactivate_lid()
   - tc_mod.set_block_temperature(temperature := __PARAMETERS["thermo_temp"]["value"])
   (default = 4 °C; pre-cool for clip reactions).

   7.3 LOAD DESTINATION PLATE ON THERMOCYCLER
   - DESTINATION_PLATE_TYPE := __LABWARES["clip_plate"]["id"]
   → "4ti0960rig_96_wellplate_200ul"
   - destination_plate := tc_mod.load_labware(DESTINATION_PLATE_TYPE)
   - destination_wells := destination_plate.wells()[0:len(parts_wells)]
   (first 12 wells will hold clip reactions).

8. SOURCE PLATES (PREFIX / SUFFIX / PART PLATES)

   - SOURCE_PLATE_TYPE := __LABWARES["clip_source_plate"]["id"]
     → "4ti0960rig_96_wellplate_200ul"

   - source_plates_keys := unique values of (prefixes_plates + suffixes_plates + parts_plates)
     → {"D2", "C2"} in this Flex layout.

   - For each key in source_plates_keys:
     source_plates[key] := protocol.load_labware(SOURCE_PLATE_TYPE, key)

   - Interpretation (Flex deck):

     - Plate in slot "D2" = linker source plate (prefixes + suffixes).
     - Plate in slot "C2" = part source plate.

9. TUBE RACK (MASTER MIX & WATER)

   - TUBE_RACK_TYPE     := __LABWARES["24_tuberack_1500ul"]["id"]
     → "e14151500starlab_24_tuberack_1500ul"

   - TUBE_RACK_POSITION := "1"

   - MASTER_MIX_WELL    := "A1"

   - WATER_WELL         := "A2"

   - MASTER_MIX_VOLUME  := 20 µL

   - tube_rack := protocol.load_labware(TUBE_RACK_TYPE, TUBE_RACK_POSITION)

   - master_mix := tube_rack[MASTER_MIX_WELL]

   - water      := tube_rack[WATER_WELL]



PARAMETER FLAGS (FROM __PARAMETERS)

10. SET MIX FLAGS

    - If __PARAMETERS["premix_linkers"]["value"] == "Yes":
      Mix_linkers_bool := True
      Else:
      Mix_linkers_bool := False

    - If __PARAMETERS["premix_parts"]["value"] == "Yes":
      Mix_parts_bool := True
      Else:
      Mix_parts_bool := False



LINKER PRE-MIX FUNCTION (mix_linkers_function)

11. FLOW RATES FOR LINKER MIXING

    - If robot_type == "Flex" AND PIPETTE_TYPE is Flex single-channel (50 µL):
      pipette.flow_rate.aspirate := 20 µL/s
      pipette.flow_rate.dispense := 20 µL/s
      pipette.flow_rate.blow_out := 35 µL/s

    - Elif robot_type == "OT-2" AND PIPETTE_TYPE == "p20_single_gen2":
      pipette.flow_rate.aspirate := 8 µL/s
      pipette.flow_rate.dispense := 8 µL/s
      pipette.flow_rate.blow_out := 15 µL/s

    - Else:
      RAISE error ("Don't have a single-channel P20 or P50 pipette loaded")

12. RELATIVE RATE LABELS

    - high := 2.0
    - normal := 1.0
    - slow := 0.4
    - vslow := 0.2

13. COMPUTE LINKER MIX VOLUME LIMIT

    - If robot_type == "Flex":
      linkers_volume := min(__PARAMETERS["linkers_volume"]["value"], 100)
      (Flex cap 100 µL; default parameter 20 µL → linkers_volume = 20 µL)

    - Elif robot_type == "OT-2":
      linkers_volume := min(__PARAMETERS["linkers_volume"]["value"], 40)
      (OT-2 cap 40 µL)

    - Else:
      RAISE error ("Wrong Robot!")

14. BUILD UNIQUE PREFIX / SUFFIX SETS

    - prefixes_unique:

      - Build list of [plate,well] from clips_dict["prefixes_plates"], clips_dict["prefixes_wells"].
      - prefixes_unique := unique rows of that 2D array.

    - suffixes_unique:

      - Build list of [plate,well] from clips_dict["suffixes_plates"], clips_dict["suffixes_wells"].
      - suffixes_unique := unique rows.

15. IF Mix_linkers_bool == True, MIX EACH UNIQUE PREFIX WELL

    For each index clip_num in 0 .. len(prefixes_unique)−1:

    - src_plate_id := prefixes_unique[clip_num, 0]  (e.g. "D2")
    - src_well_id  := prefixes_unique[clip_num, 1]  (e.g. "A8")

    15.1 PICK UP fresh tip.
    15.2 ASPIRATE linkers_volume/2 (e.g. 10 µL) from source_plates[src_plate_id][src_well_id].bottom(2 mm) at rate=normal.
    15.3 DISPENSE same volume to bottom(3 mm) at rate=high.
    15.4 Repeat 15.2–15.3 three times (total four mix strokes).
    15.5 Final gentle mixing stroke:
    - ASPIRATE linkers_volume/2 at bottom(2 mm) at rate=normal.
    - DISPENSE linkers_volume/2 at bottom(log(linkers_volume) mm) at rate=slow with push_out = linkers_volume/20 (≈1 µL).
    15.6 MOVE tip to 5 mm below the top of src well (top(−5 mm)).
    15.7 DELAY 1 second.
    15.8 BLOW OUT.
    15.9 TOUCH TIP (radius 0.9, v_offset −5 mm, speed 10).
    15.10 DROP tip.

16. REPEAT MIXING FOR EACH UNIQUE SUFFIX WELL

    - Same pattern as step 15, but over suffixes_unique (unique suffix wells on plate "D2").



PART PRE-MIX FUNCTION (mix_parts_function)

17. FLOW RATES FOR PART MIXING

    - If robot_type == "Flex" AND PIPETTE_TYPE is Flex single-channel:
      pipette.flow_rate.aspirate := 20 µL/s
      pipette.flow_rate.dispense := 20 µL/s
      pipette.flow_rate.blow_out := 35 µL/s

    - Elif robot_type == "OT-2" AND PIPETTE_TYPE == "p20_single_gen2":
      pipette.flow_rate.aspirate := 8 µL/s
      pipette.flow_rate.dispense := 8 µL/s
      pipette.flow_rate.blow_out := 15 µL/s

18. RELATIVE RATE LABELS

    - high := 2.0, normal := 1.0, slow := 0.4, vslow := 0.2

19. COMPUTE PART MIX VOLUME LIMIT

    - If robot_type == "Flex":
      parts_volume := min(__PARAMETERS["parts_volume"]["value"], 100)
    - Elif robot_type == "OT-2":
      parts_volume := min(__PARAMETERS["parts_volume"]["value"], 40)
    - Else:
      RAISE error ("Wrong Robot!")

20. BUILD UNIQUE PART SETS

    - parts_unique := unique (plate,well) pairs from (parts_plates, parts_wells).

21. IF Mix_parts_bool == True, MIX EACH UNIQUE PART WELL

    For each clip_num in 0 .. len(parts_unique)−1:

    - src_plate_id := parts_unique[clip_num, 0]  (e.g. "C2")
    - src_well_id  := parts_unique[clip_num, 1]

    21.1 PICK UP fresh tip.
    21.2 SET pipette.well_bottom_clearance.aspirate := 2 mm; dispense := 1 mm.
    21.3 ASPIRATE parts_volume/2 (e.g. 10 µL) from bottom(2 mm) at rate=normal.
    21.4 DISPENSE same to bottom(3 mm) at rate=high.
    21.5 Repeat aspirate/dispense cycles three times total.
    21.6 Final gentle stroke:
    - ASPIRATE parts_volume/2 at bottom(2 mm) at rate=slow.
    - DISPENSE parts_volume/2 at bottom(log(parts_volume) mm) at rate=slow, push_out ≈ log(parts_volume).
    21.7 MOVE to top(−5 mm).
    21.8 DELAY 1 second.
    21.9 BLOW OUT.
    21.10 TOUCH TIP.
    21.11 DROP TIP.



CLIP SETUP (main clip() function)

22. CALL PRE-MIX FUNCTIONS

    - mix_linkers_function(Mix_linkers_bool, clips_dict, pipette, source_plates, PIPETTE_TYPE)
    - mix_parts_function(Mix_parts_bool,  clips_dict, pipette, source_plates, PIPETTE_TYPE)

23. RESET CLIP SETUP FLOW RATES

    - If robot_type == "Flex" AND PIPETTE_TYPE is Flex single-channel:
      pipette.flow_rate.aspirate := 20 µL/s
      pipette.flow_rate.dispense := 20 µL/s
      pipette.flow_rate.blow_out := 35 µL/s

    - Elif robot_type == "OT-2" AND PIPETTE_TYPE == "p20_single_gen2":
      pipette.flow_rate.aspirate := 8 µL/s
      pipette.flow_rate.dispense := 8 µL/s
      pipette.flow_rate.blow_out := 15 µL/s

    - Speed labels:
      high := 2.0; normal := 1.0; slow := 0.5; vslow := 0.2.

24. DISTRIBUTE MASTER MIX TO ALL DESTINATION WELLS

    24.1 SET clearances:
    - pipette.well_bottom_clearance.aspirate := 1 mm
    - pipette.well_bottom_clearance.dispense := 0 mm

    24.2 PICK UP fresh tip.

    24.3 pipette.distribute(
    volume := MASTER_MIX_VOLUME (20 µL),
    source := master_mix,
    dests  := destination_wells (first 12 wells),
    blow_out := True (in source),
    blowout_location := "source well",
    new_tip := "never",
    rate := slow
    )

    24.4 DROP tip.

25. DISTRIBUTE WATER TO ALL DESTINATION WELLS

    25.1 SET clearances:
    - pipette.well_bottom_clearance.aspirate := 1 mm
    - pipette.well_bottom_clearance.dispense := 3 mm

    25.2 PICK UP fresh tip.

    25.3 pipette.distribute(
    volume_list := water_vols (per reaction water volume),
    source      := water,
    dests       := destination_wells,
    blow_out    := True (source),
    blowout_location := "source well",
    new_tip := "never",
    rate := slow
    )

    25.4 DROP tip.

26. TRANSFER PREFIX, SUFFIX, AND PART FOR EACH CLIP REACTION (WITH MIXING)

    For clip_num from 0 to len(parts_wells)−1 (0..11):

    26.1 COMMON SETTINGS
    - dest := destination_wells[clip_num]
    - pipette.well_bottom_clearance.aspirate := 2 mm
    - pipette.well_bottom_clearance.dispense := 2 mm

    (a) PREFIX TRANSFER (1 µL)

    - src_prefix_plate := source_plates[prefixes_plates[clip_num]]   (plate "D2")
    - src_prefix_well  := prefixes_wells[clip_num]                   (e.g. "A8")

    i.   PICK UP fresh tip.
    ii.  ASPIRATE 1 µL from src_prefix_plate[src_prefix_well].bottom(1 mm) at rate=slow.
    iii. DISPENSE 1 µL into dest.bottom(2 mm) at rate=slow.
    iv.  MIX in dest:
    - ASPIRATE 4 µL from dest.bottom(1 mm), DISPENSE 4 µL to dest.bottom(3 mm) at rate=high.
    - Repeat aspirate(4 µL, bottom(1)) / dispense(4 µL, bottom(3)) twice more.
    - ASPIRATE 5 µL from dest.bottom(2 mm) at rate=slow;
    DISPENSE 5 µL to dest.bottom(3 mm) at rate=slow with push_out=1 µL.
    v.   MOVE to dest.top(−5 mm).
    vi.  DELAY 1 second.
    vii. BLOW OUT.
    viii.TOUCH TIP.
    ix.  DROP tip.

    (b) SUFFIX TRANSFER (1 µL)

    - src_suffix_plate := source_plates[suffixes_plates[clip_num]]  (plate "D2")
    - src_suffix_well  := suffixes_wells[clip_num]

    i.   PICK UP fresh tip.
    ii.  ASPIRATE 1 µL from src_suffix_plate[src_suffix_well].bottom(1 mm) at rate=slow.
    iii. DISPENSE 1 µL into dest.bottom(3 mm) at rate=slow.
    iv.  MIX in dest:
    - Aspirate/dispense 4 µL between bottom(1 mm) and bottom(3 mm) at rate=high, repeated several times.
    - Final 5 µL slow mix from bottom(2 mm) to bottom(3 mm) with push_out=1 µL.
    v.   MOVE to dest.top(−4 mm).
    vi.  DELAY 1 second.
    vii. BLOW OUT.
    viii.TOUCH TIP.
    ix.  DROP tip.

    (c) PART TRANSFER (parts_vols[clip_num] µL)

    - src_part_plate := source_plates[parts_plates[clip_num]]   (plate "C2")
    - src_part_well  := parts_wells[clip_num]
    - part_vol       := parts_vols[clip_num]  (range ~1–2.5 µL)

    i.   PICK UP fresh tip.
    ii.  ASPIRATE part_vol from src_part_plate[src_part_well].bottom(1 mm) at rate=slow.
    iii. DISPENSE part_vol into dest.bottom(3 mm) at rate=slow.
    iv.  MIX in dest (stronger mix to homogenise full clip reaction):
    - Repeat three times:
    - ASPIRATE 15 µL from dest.bottom(1 mm) at rate=normal.
    - DISPENSE 15 µL to dest.bottom(3 mm) at rate=high (first two) or normal (third).
    - Final slow 15 µL mix: aspirate from bottom(2 mm), dispense to bottom(3 mm) at rate=slow, push_out=2 µL.
    v.   MOVE to dest.top(−5 mm).
    vi.  DELAY 1 second.
    vii. BLOW OUT.
    viii.TOUCH TIP.
    ix.  DROP tip.

    (Result: each clip well now contains master mix + water + premixed linkers + part, thoroughly mixed.)



THERMOCYCLER CLIP PROGRAM

27. AFTER clip(--clips_dict) COMPLETES:

    27.1 CLOSE thermocycler lid:
    - tc_mod.close_lid()

    27.2 SET lid temperature to 105 °C:
    - tc_mod.set_lid_temperature(105)

    27.3 RUN LIGATION / BsaI DIGEST CYCLE PROFILE
    - profile := [
    {temperature: 37 °C, hold_time_minutes: 2},
    {temperature: 20 °C, hold_time_minutes: 1}
    ]

    
     - tc_mod.execute_profile(steps=profile, repetitions=30, block_max_volume=30 µL)  
       (30 cycles of 37 °C 2 min / 20 °C 1 min).  
    

    27.4 POST-CYCLE HOLDS
    - tc_mod.set_block_temperature(37 °C, hold_time_minutes=10, block_max_volume=30 µL)
    (enhanced final BsaI cleavage at 37 °C).
    - tc_mod.set_block_temperature(65 °C, hold_time_minutes=20, block_max_volume=30 µL)
    (heat inactivation of BsaI HFv2 and ligase).
    - tc_mod.set_block_temperature(4 °C, hold_time_minutes=2, block_max_volume=30 µL)
    (short cool-down).

28. LID STATE AFTER CLIP REACTION

    - If __PARAMETERS["clip_keep_thermo_lid_closed"]["value"] == "Yes":
      Thermo_lid_bool := True
      Else:
      Thermo_lid_bool := False

    28.1 If Thermo_lid_bool == True:
    - tc_mod.deactivate_lid()
    - tc_mod.set_block_temperature(4 °C)
    (block stays at 4 °C indefinitely; lid remains CLOSED).

    28.2 Else (Thermo_lid_bool == False):
    - tc_mod.set_lid_temperature(45 °C)
    - tc_mod.deactivate_lid()
    - tc_mod.open_lid()



SIMULATION OUTPUT (OPTIONAL)

29. COMMAND LOG (simulate mode)

    - FOR each line in protocol.commands():
      PRINT(line)  (human-readable log of tip pickups, transfers, thermocycler actions, etc.).

END RUN
